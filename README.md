# Grokking: Watching a Neural Network Discover Mathematics

Interactive [marimo](https://marimo.io) notebook exploring grokking — the phenomenon where a neural network suddenly generalises long after memorising training data.

## Papers
- Power et al. (2022) — [Grokking: Generalization Beyond Overfitting](https://arxiv.org/abs/2201.02177)
- Nanda et al. (2023) — [Progress Measures for Grokking via Mechanistic Interpretability](https://arxiv.org/abs/2301.05217)

## Run locally
```bash
uvx marimo run grokking_v3.py
```

## Run on molab (free GPU)
Upload `grokking_v3.py` to [molab.marimo.io](https://molab.marimo.io) and enable the GPU.
